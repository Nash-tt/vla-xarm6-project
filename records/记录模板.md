# 开发记录模板

## 开发条目

### YYYY-MM-DD：事项名称

- **目标与背景**：本次要解决什么问题，为什么开展这项工作。
- **代码与版本**：分支、commit、涉及的文件或函数。
- **实施与判断依据**：修改内容、选择该方案的理由；影响决策的失败尝试。
- **验证**：测试输入、操作、结果、证据位置；区分本机测试、影子测试与真机执行。
- **结论与限制**：已证明的结论、未证明的部分。
- **后续事项**：需要进一步验证或修改的内容。

## 问题条目

### P-编号：问题名称

1. **现象与影响**：触发条件、预期结果、实际结果。
2. **定位证据**：日志、复现步骤、相关代码；将推测标为推测。
3. **原因**：直接原因与形成条件；尚不明确时如实记录。
4. **处理**：实际修改、失败尝试、涉及文件。
5. **验证与状态**：解决、部分解决或待处理；验证结果及范围。
6. **经验与适用边界**：后续如何避免复发，何时需要重新评估。

## 训练实验条目

### E-编号：模型与实验目标

| 字段 | 内容 |
|---|---|
| 实验假设、对照组与唯一变化 | 待填写 |
| 代码 commit、LeRobot commit、环境版本 | 待填写 |
| 数据集 ID、版本或摘要、回合数、帧数、划分方式 | 待填写 |
| 图像尺寸、状态与动作维序、单位、归一化方式 | 待填写 |
| 模型、底座 repo 与 revision、初始化方式 | 待填写 |
| 训练模块、冻结模块、总参数及可训练参数 | 待填写 |
| LoRA target_modules、r、alpha、dropout、全量训练模块 | 不适用或待填写 |
| 优化器、学习率、betas、weight decay、梯度裁剪 | 待填写 |
| 调度器、warmup、decay steps、最终学习率 | 待填写 |
| batch size、梯度累积、步数、seed、workers | 待填写 |
| chunk size、n_action_steps、精度、AMP、梯度检查点 | 待填写 |
| GPU 型号、显存测量口径、峰值、采样频率 | 待填写 |
| 开始与结束时间、时区、训练环耗时、总耗时、步时 | 待填写 |
| 实际完成步数、状态、checkpoint、恢复来源 | 待填写 |
| 训练 loss、验证集指标、逐维误差、任务成功率 | 未测量或待填写 |
| 原始配置、日志、评估产物位置 | 待填写 |
| 结论、限制与下一步 | 待填写 |

运行开始时填写目标与计划；首个 checkpoint 后核对实际配置；运行结束后补充耗时和结果。中断和恢复追加条目，不覆盖原记录。进行真机评估时，另外记录接触条件、力阈值、影子测试结果与执行范围。
