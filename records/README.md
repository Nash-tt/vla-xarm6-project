# 持续开发记录

本目录保存一个开发周期内的过程与证据。当前技术方案统一放在 [技术文档](../docs/README.md)，本目录不再重复完整实现说明。

| 文件 | 更新时机 | 内容 |
|---|---|---|
| [开发日志](开发记录.md) | 实质性开发任务完成时 | 目标、改动、验证、判断与后续事项 |
| [问题记录](问题记录.md) | 出现有复用价值的问题时 | 现象、原因、处理、证据与适用边界 |
| [训练实验](训练实验.md) | 启动、恢复、结束及评估时 | 实验目标、实际配置、资源、进度和结果 |
| [部署实验](部署实验.md) | 回放、影子和真机验证后 | 执行频率、网络延迟、限速、跟踪与实验边界 |
| [记录模板](记录模板.md) | 新增条目时参考 | 统一字段与证据要求 |
| [training/](training/) | 有 checkpoint 与日志时 | 配置摘要和来源 SHA-256 |

每个训练实验使用独立编号。计划值与实测值分开记录；没有结束标记或评估证据时不写成已完成或已验证。开发者和助手在任务内维护这些文件，当前没有后台自动更新机制。
