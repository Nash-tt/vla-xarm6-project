# 03 · roll 角度表示：归一化尺度被放大 22 倍

> 工具：`tools/trim_scan_segments.py --unwrap-roll`　相关：`pi0_ultrasound_lora/unwrap_roll.py`

## 现象

同一批轨迹被制成了两份数据集，初期认为二者只是同一数据的不同存储形式。
直至发现旧的一次 20k 训练结果中，**roll 维度基本未被学到**：
预测的 roll 近似为一条直线，而示范数据中该维度有明确变化。

## 原因：360 的整数倍

两份数据集确实来自**同一批轨迹**：

- 非 roll 维度逐位相同
- roll 维度仅相差 360 的整数倍，**残差严格为 0**

差异仅在于角度表示方式：

| 版本 | 约定 | roll 实际范围 | std |
|---|---|---|---|
| `..._pi0_6d_rollunwrap` | 展开（unwrap） | `[163.967, 193.039]`（连续） | 7.77 |
| `..._smolvla_6d_no_depth` | wrap 至 ±180 | 跨 0 点分为两簇 | **172.07** |

展开版本是一段连续角度；wrap 版本将其折叠至 `[-180, 180]`，
于是原本连续的区间在 ±180 处被截断，形成相距较远的两簇。

**std 由 7.77 变为 172.07，放大 22 倍。**

## 对回归型策略的影响

三项后果同时出现：

1. **归一化尺度被放大 22 倍。** LeRobot 默认对 action 采用 `MEAN_STD`，即除以 std。
   std 增大 22 倍意味着该维度被压缩 22 倍，梯度尺度随之减小；
   在与其他维度共享学习率的前提下，该维度难以被学习。

2. **均值落在数据中不存在的区间。** wrap 后的均值为 22.99°，
   恰位于两簇之间的空档——**数据中不存在该值**。
   以该均值做中心化，等于为模型提供错误的原点。

3. **相邻帧之间出现 359° 的跳变。** ep22 在物理上跨越 180°，
   wrap 后同一回合内相邻两帧的目标值相差 359°，
   对模型而言这是一次无依据的大幅动作。

### 代价量化

旧 20k run 使用 wrap 版本配合 `ACTION: MEAN_STD`，代价可定量描述：

| | 物理 roll 区间 `[163.967, 193.039]` 归一化后 |
|---|---|
| wrap 版（旧 20k） | `z ∈ [0.8193, 0.9883]`，**跨度 0.169**，集中于 z≈+0.9 |
| 展开版（当前） | `z ∈ [−1.4424, +2.2719]`，**跨度 3.71** |

即旧模型观测到的 roll 目标**近似为常数**（集中于 +0.9 附近，仅占 0.169 个标准差）。
新数据集使同一物理区间展开至 3.71 个标准差。

**结论：该 20k checkpoint 在 roll 维度上等同于未训练，不可用作基线对比。**

## 处理

不就地修改数据（保持原数据集不变），而是**输出统一口径的副本**：

```bash
python tools/trim_scan_segments.py --src <原数据集> --dst <裁剪版> --unwrap-roll
```

`--unwrap-roll` 默认为关闭。解 wrap 后，smolvla 版本的 roll 统计与 pi0 版本**逐位相同**。

**已确定的口径（2026-10-12）：**

- π0 训练使用 `vla_batch_20261007_pi0_6d_rollunwrap_scan`（原本即为展开）
- SmolVLA 训练使用 `vla_batch_20261007_smolvla_6d_no_depth_rollunwrap_scan`（解 wrap 后）

## 一处易错的验证细节

比较两个版本时**必须使用环绕距离**：

```python
d = (d + 180) % 360 - 180
```

直接计算 `a - b` 会在跨 0 点处得到 **359.8° 的虚假偏差**，
进而误判两份数据不一致——而实际上二者仅相差 360 的整数倍。

同理，裁剪的边界判据本身也采用环绕口径，
因此 `--unwrap-roll` 开关**不影响裁剪结果**（切分位置一致），仅影响数值表示。

## 结论

1. **同一物理量可存在多种合法表示，而框架对表示方式存在隐含假设。**
   角度、四元数与欧拉角、坐标系均属此类。
   在将数据交由框架处理之前，应先确认框架期望的表示方式。
2. 22 倍这一量级说明：归一化会**放大**表示选择的影响。
   `MEAN_STD` 默认除以 std，任何人为扩大分布的因素都会直接削弱该维度的学习。
3. 某一维度学习效果不佳，未必源于模型容量或学习率。
   **应首先检查该维度归一化后的取值分布**，其效率高于参数调整。
