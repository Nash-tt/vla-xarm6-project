# xArm6 超声扫描：模型训练与远程执行

本项目使用自采机器人示范数据，训练 xArm6 携带超声探头完成连续扫描。模型读取 RGB 图像、超声图像和末端实际位姿，预测六维末端目标位姿。GPU 机器负责数据处理、训练与策略推理；Windows 工控机负责传感器采集和机器人执行。

截至2026-10-14，本轮实验过程与问题复盘见 [持续开发记录导航](records/README.md)。本次同步发布文档和实验摘要；描述的多模型接入、相对动作训练与等待模式部分代码仍在本地工作版本，尚未随此次文档提交发布，不能直接把仓库当前代码视为对应的可部署版本。

本文是项目唯一总入口。技术说明统一位于 `docs/`，持续开发记录统一位于 `records/`。各代码目录不再分别维护说明文档。

## 4. 当前状态与限制

2026-10-13 文档核对基线为 `e8d95cc`；已核对本仓库关键实现与本机部分训练产物。SmolVLA 扫描段训练、ACT 训练均有 20,000 步完成日志；π0 首轮有 12,250 步 checkpoint。其他实验状态和证据见训练实验记录。

采集端输出的便携训练文件夹与 LeRobot v3 数据集是两种格式，仓库中尚未找到可明确核对的完整转换入口。独立评估和真机任务成功率尚未系统汇总，不能仅根据训练损失判断部署效果。

2026-10-13已整合工控机提供的10秒和70秒有界真机实验报告，来源及结论边界见部署实验。报告仍有长动作间隙，尚未证明持续稳定15 Hz；本次未独立复算原始真机日志。

仓库不包含数据集、模型权重、厂商 SDK 或实际连接凭据。2026-10-13 已在工控机 D 盘独立目录部署 ACT/SmolVLA 客户端并完成配置检查及单帧网络回放；模型仍在本机 GPU 推理，实时影子已执行但直接目标检查未通过，运动测试尚未进行。示例中的路径与地址均需按部署环境填写。
